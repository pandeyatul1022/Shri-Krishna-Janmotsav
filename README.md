# 🚩 श्रीकृष्ण जन्मोत्सव 2026 (Shri Krishna Janmashtami Digital Celebration)

> श्रीकृष्णजन्मोत्सवस्य मनोरमं डिजिटल-प्रस्तुतीकरणम्।

A hyper-realistic, luxury digital presentation and live countdown timer for **Shri Krishna Janmashtami 2026**. Built with vanilla HTML5, CSS3 glassmorphism & 3D transforms, HTML5 Canvas animation engine, and Bootstrap 5.

---

## ✨ Key Features & Highlights

- 🌌 **Dynamic Celestial Night Canvas Engine**: Interactive starfield with smooth twinkling sinusoidal animation, 4-point lens flares, and shooting meteors.
- ⏳ **3D Split-Flap Glass Cards**: Realistic depth countdown display showing Days, Hours, Minutes, and Seconds.
- 🏯 **3D Mathura Fortress Jail Gate Opening**: Automatic 3D Mathura prison gate shattering animation, divine celestial light burst, and interactive dungeon torches when the timer hits zero.
- 🌸 **Particle Flower Shower Cascade**: Falling flower petals (`🌸 🌺 🌻 🪷 🌼 🏵️`) with realistic physics, sway, and automatic DOM memory cleanup.
- 📱 **Mobile & Touch Responsive**: Full PWA support (`manifest.json`), custom breakpoints down to 320px screens, and touch-optimized interactions.
- 🔍 **Production SEO & Social Sharing**: Full Open Graph (OG) meta tags, Twitter card support, and JSON-LD Event Schema for Google Search indexing.
